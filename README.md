# 超级跳跃工坊

手机上的开放式地图跳跃游戏。带账号系统、地图工坊、排行榜、地图码搜索。

**零 npm 依赖**，只用 Node 内置模块，一个 `node server.mjs` 就能跑。

---

## 快速启动

```powershell
cd C:\Users\TTND\Documents\mario-online
node server.mjs
```

启动后会打印三个地址：

```
本机:   http://localhost:8787
局域网: http://192.168.x.x:8787     ← 手机连同一个 Wi-Fi 用这个
```

手机浏览器打开局域网地址即可玩。

## 已经实现的功能

### 操作
| 操作 | 效果 |
| --- | --- |
| 左 / 右 | 移动，带加速和摩擦（冰面上会打滑） |
| 跳（第一下） | 地面起跳，长按跳更高 |
| 跳（空中再按） | **二段跳** |
| 贴墙时按住方向 | **攀墙**，往上爬（有体力条，约 1.15 秒） |
| 体力耗尽 | 变成缓速下滑 |
| 贴墙时按跳 | **反墙跳**：弹向反方向，且刷新二段跳 |

### 地图组件（10 种）
`地面 #` `金属 M` `冰面 ~` `弹簧 =` `尖刺 ^` `金币 o` `星星 *` `出生点 S` `终点 G` `橡皮 .`

### 系统
- 注册 / 登录（scrypt 加盐哈希，不存明文密码）
- 相机拍照设头像（浏览器摄像头权限）
- 地图工坊：手指点画，实时预览，本地试玩后发布
- 地图码：6 位，URL 安全字符，支持按码搜索
- 排行榜：总榜（试玩次数）、难度榜（自动评级 1~5 星）
- 试玩计数：进图算一次，通关单独计「通关数」
- 深链分享：`?map=地图码` 直接开玩

## 技术要点

### 物理
参数取自「派对制造」（`party-maker`）的实测手感：

```js
GRAV 1750, MAXFALL 1050, RUN 265, ACC 2600, FRIC 2400, JUMPV -640
```

固定步进 **17ms/帧**（约 58.8 fps），用累加器驱动，掉帧时补算但不追帧超过 5 步。

### 关卡格式
纯文本网格，一行一串字符，服务端和客户端共用：

```
"....................",
".......o..o.........",
"......#######.......",
"..S..............G..",
"####################"
```

发布时服务端会做白名单过滤，非法字符自动变空地；并且强制校验**至少一个出生点、一个终点**。

### 自动难度
服务端按尖刺数量、地形起伏高度差、平台密度、空白占比加权算分，映射到 1~5 星。不是随机标的。

### 坐标系
逻辑视口按屏幕比例自适应（横屏约 24×11 格），`TILE = 32`。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/register` | 注册，返回 token |
| POST | `/api/login` | 登录，返回 token |
| GET | `/api/me` | 当前用户 |
| POST | `/api/me/avatar` | 上传头像（dataURL） |
| POST | `/api/maps` | 发布地图（需登录） |
| GET | `/api/maps?sort=plays\|difficulty\|new&q=关键词` | 列表 / 搜索 |
| GET | `/api/maps/:code` | 取单张地图（含网格） |
| POST | `/api/maps/:code/play` | 试玩计数 |
| DELETE | `/api/maps/:code` | 删自己的地图 |
| GET | `/api/leaderboard` | 双榜单 |
| GET | `/api/info` | 服务信息 + 局域网 IP |

鉴权：`Authorization: Bearer <token>`。

## 让外网的人也能玩

现在跑在本机，手机连同一个 Wi-Fi 才能访问。要让**不同地区的人都能打开**，有三条路：

### 1. 临时公网隧道（现在用的）
```powershell
lt --port 8787
```
会给你一个 `https://xxx.loca.lt` 地址，全球可访问。
**缺点**：电脑关机就断，地址每次重启会变。

### 2. 部署到云主机（推荐长期用）
因为它零依赖，任何能跑 Node 的地方都行：

- **Railway / Render / Zeabur**：连 GitHub 仓库，一行启动命令 `node server.mjs` 即可
- **云服务器**：装 Node，`git clone` 后 `node server.mjs`，前面套 Nginx
- 注意：`data/` 目录要挂持久化磁盘，否则重启数据会没

### 3. 云函数 / 静态托管
`public/` 可以放任何静态托管（Cloudflare Pages / Vercel），
但 API 需要单独部署成函数，且要把 JSON 文件存储换成数据库。

## 已知限制

- 地图尺寸工坊固定 `64×20` 格；服务端上限 `260×80`，可以改 `editor.js` 的 `EDIT_COLS/EDIT_ROWS`
- 存储是单文件 JSON，适合小规模；并发写入靠 120ms 合并写盘，人多要换 SQLite
- 没有找回密码 / 邮箱验证
- 头像是浏览器直出 JPEG，没有做二次压缩
- 隧道方案下所有流量走你电脑，电脑关机就玩不了
